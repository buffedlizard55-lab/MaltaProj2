Methodology & sources

Every CS2 fixture in the HotSpawn pick'em lobby · external lines only · HotSpawn used for fixture discovery, never as a probability

Every number on this board is produced by the pipeline in this repository from a named public source. Nothing is typed in by hand, nothing is estimated silently, and HotSpawn is never used as a probability input — only as the list of fixtures to price.

1. Fixtures (discovery only)

The lobby's own public JSON API is read by the runner: https://phpstack-1372681-6459848.cloudwaysapps.com/api/v1/fixtures (page: play.hotspawn.com/lobby). It returned 92 CS2 fixtures for the pick'em window. The lobby's "picked %" crowd number is displayed on each card for reference only and never enters a calculation.

3. Matching rules

  1. Both participants must match after documented normalisation (case, accents, punctuation, club suffixes, and an explicit alias table), in either order; a reversed source listing has its prices reversed.
  2. A quote is accepted only when its own schedule agrees with the fixture within 90 minutes. Kalshi's settlement rule is parsed for the original schedule — the exchange's padded occurrence_datetime is deliberately ignored.
  3. One quote is assigned to at most one fixture; ambiguous candidates are rejected and logged.
  4. Quotes that fail the quality gate are rejected, not published: empty or far-too-wide Kalshi books, and aggregator quotes that repeat the identical even price across unrelated matches (placeholders).

4. Probability maths

Bookmaker decimal odds: q_i = 1 / odds_i, then p_i = q_i / (q_a + q_b) (proportional no-vig; the book margin q_a + q_b − 1 is printed on the card). Kalshi: p_i = mid_i / (mid_a + mid_b) with mid_i = (yes_bid + yes_ask) / 2. When several named sources quote the same match the card shows their arithmetic mean; the per-source values are listed under it. These are derived quantities, not forecasts and not source quotes.

5. Originated lines (matches no market prices)

Where no external price exists the board originates its own line, in this order, and says so on the card:

  1. Market-graph Bradley-Terry. Every collected moneyline is one observation of logit(p) = strength_A − strength_B; strengths are fitted by maximum likelihood over the whole graph (including matches outside the pick'em). A team needs at least 3 collected observations against at least two different opponents to carry a usable strength. Graph: 112 observations over 103 teams. Held-out (refit without the fixture, predict it, compare with the market): 2 fixture(s), mean absolute error 0.011, Brier 0.0002 — thin, because the identification rule excludes everything else.
  2. Valve Regional Standings. p = sigmoid((points_A − points_B)/scale) with the scale fitted against the priced fixtures: 120.1 points, calibration on 14 fixtures, mean absolute error 0.1929 (deeper books only: 9 fixtures, MAE 0.1829). Because that error is large, the model output is clamped to [0.1, 0.9] and every row using it says "originated".

6. Reproducing this board

  • Collection runs on a GitHub runner (network access is restricted in the authoring sandbox): python3 proof/42580809/run/fetch_fixtures.py && python3 proof/42580809/run/fetch_reference.py && python3 proof/42580809/run/probe_sources.py && python3 proof/42580809/run/explore_sources.py && python3 proof/42580809/run/inspect_pinnacle.py && python3 proof/42580809/run/collect_lines.py — raw payloads land in proof/42580809/evidence/.
  • Join and derive: python3 proof/42580809/build_board.py → data/board_42580809.json, plus every accept/reject decision in evidence/matching.json.
  • Originate: python3 proof/42580809/originate.py → data/originated_42580809.json.
  • Publish: python3 proof/42580809/build_site.py → this section.

7. Limits, stated plainly

  • 62 of 92 listed fixtures have a kickoff already in the past; they stay listed (the lobby still shows them) and stay blank.
  • Aggregator-only rows are weaker evidence than bookmaker rows and are marked as such everywhere.
  • Low-tier tournaments (Elisa BreakOut, CCT play-ins, FRAG University) are barely priced by the reachable sources; that is why the originated model exists and why some rows remain blank.
  • No value on this board is filled in by hand, and no HotSpawn number is used as a probability.
