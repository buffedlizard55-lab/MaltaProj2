Medium PA-CONST-01 · The rating slope C is correctly derived but mis-cited as a literal Valve constant

The boards cite model/fit.js for C=0.0056000078, but fit.js does not contain that number. The value reproduces to 2e-11 as Q*g(RD) from Valve's published Glicko Q (glicko.js; Q=ln(10)/400=0.005756462732485115) at fit.js default RD=75.0 -> 0.005600007780351016. The derivation is documented correctly in scripts/f7279a54/core.py (VALVE_Q/VALVE_G/VALVE_C); the method-page citations that call C a Valve-published fit.js constant should cite glicko.js + fit.js (RD=75) instead. No probability changes if corrected.
