Method

Short version: eligible external prices are de-vigged and averaged. Only matches without eligible prices use a model built on Valve's official CS2 standings. The model's steepness is learned from the bookmaker prices. If no bookmaker prices the match, the calibrated model alone gives the line. If a team has no official rating and no bookmaker prices the match, the row stays blank and is flagged.

1. Which matches

The fixture list comes from the public HotSpawn lobby (play.hotspawn.com/lobby): the page embeds the response of the lobby's own /api/v1/fixtures call in its Angular transfer state, and the same public endpoint is also read directly each run because the page is served from a cache (its Age header is recorded on the Flagged page). Only page-listed scheduled matches with a future lock are open. API-only fixtures are not advertised as lobby coverage. HotSpawn data is used only to know which matches exist and when they lock — crowd pick percentages are not read.

2. Bookmaker and exchange prices

  • Pinnacle — public guest odds API used by pinnacle.com; full-match moneyline (period 0, not alternate, status open). American odds converted to decimal.
  • Bovada — public Counter-Strike 2 coupon JSON used by bovada.lv; main-period moneyline.
  • Melbet — public LineFeed JSON (CS2 leagues only); match winner market.
  • Kalshi — CFTC-regulated exchange, series KXCS2GAME; probability = midpoint of yes bid/ask, normalised over both teams. Books with a missing side or a spread wider than 10¢ are rejected.
  • Polymarket and HLTV are probed each run; their result is on the Flagged page. HLTV is not machine-readable from the automated runner, so it is not a numeric input.

Margin removal (proportional): p_A = (1/d_A) / (1/d_A + 1/d_B) where d are decimal odds (implied-probability arithmetic as documented by Smarkets). In-play prices are excluded. Market consensus = weighted mean of the per-source probabilities with weights pinnacle 2, bovada 1, melbet 1, kalshi 1 (stated modelling choice: Pinnacle is weighted higher as a low-margin bookmaker).

Joining a price to a HotSpawn match requires both team names to be equal after normalisation (case, accents, punctuation, and the generic words team / the / esports / gaming / club at the start or end removed) and the source start time to be within ±5 minutes. Missing or approximate start times are rejected; fixture and price observations must each be at most four hours old. No prefix/substring matching ("B8" never matches "B8 Academy"). Explicit aliases:

3. Valve VRS rating model

Ratings are the points in the latest official Valve Regional Standings (global, 2026_10_05). Valve's own code defines expected win rate from a points difference Δ: model/glicko.js ("rank delta of 400 points = 90% chance of victory", ev = 1/(1+10^(g·Δ/−400))) evaluated with a fixed RD of 75 in model/fit.js, giving g = 0.9728. Valve's readme notes the curve is steeper than observed results, so we fit a slope factor k: p_A = 1/(1+10^(−k·g·Δ/400)), by least squares of logit(market) on Δ over eligible fixtures with a price and two unambiguous ratings. A duplicate team name remains unverified even if one roster has a more recent counted match. Ratings older than 14 days are excluded. These freshness thresholds and the fitted model are our policy choices, not official forecasts.

Current fit: k = 0.431 (raw 0.431) on 60 fixtures (minimum 6 to fit, otherwise k = 1, Valve's own curve; k is bounded to 0.25–1.5). Mean absolute error vs market: calibrated 7.7%, Valve default 12.2%.

4. Our line and the pick

Use the eligible market consensus unchanged when available. Only otherwise use the source-backed VRS model. We do not blend a fallback model into featured market picks. Fair odds = 1/p. The PICK is the team with p ≥ 50%. Confidence: Strong ≥ 70%, Solid ≥ 60%, Lean ≥ 53%, otherwise Toss-up.

Limits

  • These are estimates, not guarantees. A model-only line is weaker than a priced one and is labelled as such.
  • Bookmaker start-time discrepancies greater than five minutes are rejected and flagged, never treated as the same verified fixture.
  • Low-tier teams are often absent from both bookmakers and VRS; those rows stay blank.
