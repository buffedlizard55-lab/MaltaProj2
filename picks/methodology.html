Method, sources and formulas

Where the fixtures come from

The lobby page play.hotspawn.com/lobby is an Angular application that reads a public JSON API. That API is the fixture source of this board: https://phpstack-1372681-6459848.cloudwaysapps.com/api/v1/fixtures. No authentication, no admin endpoint and no paywall is bypassed; the request is the same public one the page itself makes.

Where the prices come from

Only external sources are used, and every price keeps the exact URL it was read from:

  • Bovada — licensed bookmaker; 10 quoted rows in this build.
  • Pinnacle — licensed bookmaker; 14 quoted rows in this build.

How a probability is produced

For each source that quotes the match:

q_i = 1 / decimal_odds_i
p_i = q_i / (q_a + q_b) — proportional no-vig probability
overround = (q_a + q_b) - 1 — the bookmaker's margin

The published probability is the arithmetic mean of p_i over the accepted sources; the row shows how many sources were used. A single-source row is labelled as such.

How a quote is joined to a fixture

  1. Both team names must match after normalisation (accents removed, club/academy suffixes trimmed), in either order — a source that lists the pair the other way round has its prices reversed.
  2. Start times, when both sides publish one, must agree within 90 minutes. If the source publishes no start time, its league text has to correspond to the fixture's tournament.
  3. One source row is used for at most one fixture; anything ambiguous is rejected and listed on the Flagged page.
  4. Live markets are recorded but excluded from the consensus.

What is deliberately not done

  • HotSpawn's crowd “picked %” is never an input, and no other site's model output is copied.
  • No value is inferred, extrapolated or filled in from a different market.
  • A fixture without an external price shows a blank probability and is flagged as unverified.
  • Prices are pre-match only, and the retrieval timestamp is shown on the raw data files.

Raw data and re-checking

  • data/board.json — the exact board this page is rendered from.
  • data/picks_fixtures.json and data/picks_quotes.json — the raw collected rows, every row carrying its source URL and retrieval time.
