Method · formulas · sources

How every number on this desk is made

Our line

  1. Market rows (M): take the retained raw quotes (Melbet, Kalshi exchange mid, Thunderpick via bo3.gg), convert to implied probabilities, remove each book's overround (de-vig), and average. The arithmetic is re-executed by scripts/4cf64ea3/build.py on every build — the page never copies a probability it has not re-derived.
  2. Model rows (O · VRS): no eligible price exists → Valve's own Glicko expectation (ValveSoftware/counter-strike_regional_standings model/glicko.js: Q = ln(10)/400, RD = 75, g = 1/√(1+3Q²RD²/π²)), slope calibrated against real bookmaker lines (k = 0.41489160137143016 from 17 priced pairs, session fe803b80). P(A) = sigmoid(k · g · ln(10)/400 · (ptsA − ptsB)).
  3. Never: HotSpawn crowd %, HLTV fan votes, or placeholder quotes (see rejected below).

The pick ladder (contrarian but not stupid)

  • Safe pick = argmax our probability (maximises expected points).
  • Climb pick = safe pick unless one of the two swing rules fires:
    • C1 coinflip fade: market within ±8 pts of 50/50 and ≥70% of the field on one side → take the other (nearly free leverage).
    • C2 upset shot: underdog ≥ 30% (the “not stupid” floor — never swing below it), crowd differential ≥ +0.7 expected points on the row, and ≥ 2 verified context flags (underdog beat this opponent in the last 12 months; favourite changed roster/IGL/coach within 120 days; stand-in; documented rest edge). Context gates the swing; it never moves a probability.
  • Both picks are always published with the arithmetic: leverage (win chance ÷ crowd share), expected points of each side, and the cost of the swing.

Verification rules

  • Every table row carries an https source to an official page (HLTV, Liquipedia, Valve's GitHub, the book/exchange quote page, or the HotSpawn fixture listing for discovery only).
  • A value that cannot be confirmed is left blank and flagged — never inferred.
  • Research window for this build: 2026-10-15T22:22:00Z/2026-10-15T23:10:00Z.

Rejected sources

  • egamersworld uniform 1.80/1.80 micro-match widget prices — placeholder-looking equal prices on unpriced matches; never used as a line (same rejection as sessions b5436cf0/6c5bb3d6)
  • HLTV fan vote / 'win probability' widgets — crowd-style percentages, not betting lines
  • HotSpawn crowd pick % — used only for leaderboard differential; never a probability input
