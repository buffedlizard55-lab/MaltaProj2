Methodology & sources

What is measured

  1. The fixture list (teams, tournament, tier, lock time, Hotspawn link) is read from the lobby's own public fixtures API behind play.hotspawn.com/lobby.
  2. Prices are read from external, independent sources only: Pinnacle's public guest odds API, Bovada's public coupon, HLTV's published bookmaker odds and egamersworld's public odds widget.
  3. Per source the margin is removed: q = 1/decimal, p_a = q_a / (q_a + q_b). The published probability is the arithmetic mean of the per-source no-vig shares; the pick is the higher share.
  4. Hotspawn's crowd pick percentage is never an input. It is stored separately in data/961/hotspawn_reference.json and is not read by the builder.
  5. If no external price can be verified the row is blank and flagged no_external_line.

Re-verification

Every quote is stored with its URL and read time in data/961/quotes.json; the join and the arithmetic can be recomputed with python3 scripts/961/build_961.py and checked with python3 -m unittest tests.test_961. The GitHub Actions run .github/workflows/961-collect.yml re-reads every source on a schedule and commits the evidence.

Known limitations: books publish prices for their own markets and can pull a market at any time, so a quoted price is a snapshot, not a promise; HLTV rows reflect the bookmaker prices HLTV displays; fixtures with no external market anywhere are listed unverified rather than guessed.
