Methodology & sources

What is measured

  1. The fixture list (teams, tournament, tier, lock time, Hotspawn link) is read from the lobby's own public fixtures API behind play.hotspawn.com/lobby.
  2. Prices are read from external, independent sources only: Pinnacle's public guest odds API, Bovada's public coupon and egamersworld's public odds widget. HLTV is not a price source (see item 6).
  3. Per source the margin is removed: q = 1/decimal, p_a = q_a / (q_a + q_b). The published probability is the arithmetic mean of the per-source no-vig shares; the pick is the higher share.
  4. Consensus basis: pre-match quotes only. When a source reports its market as live (in-play), that price is still shown in the row but excluded from the mean and the row is flagged live_price_excluded_from_consensus; a fixture whose only quotes are live is flagged live_consensus_only.
  5. Hotspawn's crowd pick percentage is never an input. It is stored separately in data/961/hotspawn_reference.json and is not read by the builder (enforced by a test).
  6. If no external price can be verified the row is blank and flagged no_external_line.
  7. Directional cross-checks: HLTV's own wording ("<team> is the bookmaker favorite with the best odds") is compared with the board pick on Cross-checks. HLTV cannot be read by the automation runner (HTTP 403), so it is a manual cross-check only, never a price input.

Re-verification

Every quote is stored with its URL and read time in data/961/quotes.json; the join and the arithmetic can be recomputed with python3 scripts/961/build_961.py, re-checked independently (arithmetic, picks, source links, blank-unverified rule, page links) with python3 scripts/961/recheck_961.py, and unit-tested with python3 -m unittest tests.test_961. The GitHub Actions run .github/workflows/961-collect.yml re-reads every source on a schedule, runs the re-check and commits the evidence, so the board refreshes without manual input.

Known limitations: a bookmaker price is a snapshot that can be pulled at any time; some sources omit the event start time (join then rests on team names and is flagged); most LoL amateur-circuit fixtures have no external market anywhere reachable and stay blank. Published limitations and source contradictions are listed on Flagged for review.
