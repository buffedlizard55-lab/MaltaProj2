Method

  • Fixture discovery: HotSpawn Pick'ems public fixtures endpoint (discovery only) — fixtures endpoint.
  • Probabilities: external bookmakers and the EGamersWorld odds widget — never HotSpawn.
  • Join rule: both team names must match after normalisation/alias mapping and, when the source publishes a start time, it must be within 8h of the lobby start time.
  • De-vig: raw quoted odds → implied share q = 1/odds → normalised p = q / (q_a + q_b). The bookmaker margin (overround) is published per row.
  • Consensus: arithmetic mean of per-source proportional no-vig probabilities.
  • Pick: pick = higher published probability; an edge below 0.005 is published as a coin flip with no pick.
  • Freshness: market quotes older than 6h and live (in-play) markets are excluded from the published probability.
  • Estimate: p(a beats b) = 1 / (1 + 10 ** (-(R_a - R_b) / 400)) on official Valve CS2 Regional Standings points. The 400-point scale is a stated modelling assumption, not a Valve-published quantity. Published only for CS2 and always labelled as an estimate.
  • HotSpawn crowd picks: never used as an input to any probability. The board re-derives every number with the crowd fields scrambled and requires identical output (check C7).
