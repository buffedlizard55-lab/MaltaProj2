Irregularities and limitations found while verifying this board. None of them block publication; each is published with the source that shows it.

F1 · 62 of the 78 CS2 fixtures the lobby lists still carry June/July kickoff timestamps

Severity: high — inventory

HotSpawn ships these fixtures with a published start time months before the current pick'em week (status 'scheduled', stage 'waiting for information'). The lobby counts them in the week (its own tier filter reads All tiers (78) B (26) C (52) and every tournament count matches), but their lock time is long past, so they cannot be picked. They are published here with a research line where one exists and listed as unresolved where it does not — never dropped, never guessed.

F3 · HLTV refuses automated reads (HTTP 403), so it cannot be a live probability input

Severity: medium — source access

The collector probes https://www.hltv.org/matches on every run and records the result. HLTV pages are used here only for identity cross-checks that were read and linked by hand (see the alias evidence links); no scraper output feeds a line. Official Valve standings and licensed books/exchange carry every number.

F5 · Valve's newest published standings file is 16 days old (2026_10_05)

Severity: medium — rating age

Valve has not published a newer snapshot, so every VRS-model and bound row uses ratings that predate recent results. The date is shown with every rating.

F6 · 9 fixture(s) contain an organisation with more than one Valve rating row

Severity: medium — identity

Valve keeps separate rows for older rosters of the same organisation. Guessing would invent a probability, so those teams are treated as unrated unless the official details file identifies one active roster unambiguously.

source

F7 · HotSpawn crowd percentages are deliberately not used

Severity: info — method

The lobby shows how other players picked. It is not a price, has no stake behind it and would make this desk a mirror of the crowd, so the parser drops the field before any row is built. A test asserts the board never contains it.
