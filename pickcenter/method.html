Method

The same rules every run, published so any row can be checked by hand.

1. Inventory: the lobby, not a guess

Every run re-reads the public lobby page's Angular transfer state (https://play.hotspawn.com/lobby, the same /api/v1/fixtures payload the page itself calls) and keeps every Counter-Strike 2 fixture the week lists — including the ones with stale kickoff times. The page's own counters are recorded as the coverage check (listed: 78 fixtures in the inventory).

2. Prices: external only

Pinnacle, Bovada, Melbet and the Kalshi KXCS2GAME exchange are read every run. A price joins a fixture only when both team names match after normalisation (or through a published alias with linked evidence) and the start times agree within 5.0 minutes. Kalshi tickers carry US-Eastern wall-clock time and are converted with the real New York zone, so the November DST change does not shift a price.

Per-source probabilities are proportional de-vig values: p = (1/d) / (1/dA + 1/dB). The consensus is a weighted mean (Pinnacle 2.0, others 1.0). Any quote older than 8.0 hours is dropped and the row is labelled.

3. Origination: Valve's own ratings

Valve's official Regional Standings give each team a rating in points. Their published model uses a logistic curve; Valve's own README says its slope is too steep, so the slope here is fitted to book lines rather than assumed:

logit(p) = k · C · (points_A − points_B), with C = g · ln(10) / 400 for a fixed rating deviation and k = 0.4307789423656918 fitted from 60 pre-lock (fixture, market probability) pairs (source), bounded to [0.25, 1.5]. Mean absolute error on those pairs: 0.07702503405478646 versus 0.12247910190606133 for Valve's raw slope.

4. Bounds instead of invented numbers

When exactly one side is rated, the rated team's chance is computed against Valve's lowest published rating (381 pts). That is a floor for the rated team: a real opponent is at least as strong as the weakest rated team, so the true probability cannot be lower. The row says so.

5. What is never done

  • No HotSpawn crowd percentage is read, stored or used. It is a popularity poll, not a price.
  • No probability is inferred from a team name, a roster guess or a "looks stronger" judgement.
  • No price is borrowed from a differently timed fixture. Near misses are listed, not joined.
  • No missing value is filled. It stays blank and appears on the Unresolved page.

6. Refresh and verification

The workflow runs every 4 hours (and on demand) and re-captures the lobby, the books and Valve's file, then rebuilds this site. 8 checks run before anything is published: probabilities sum to 1, the pick is always the higher probability, every market line reproduces its stored consensus, every model line recomputes from its published delta and k, every originated line links the official file it came from, and the board contains no crowd data.
