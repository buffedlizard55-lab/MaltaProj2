R-C0-1 — Six open matches were reported as having no line because of a team-name mismatch, not because the team is unranked.

WROTBERRY and RoundsGG are absent from Valve's file under those names, but the file does contain WBT (standing 60, 1201 pts) and ROUNDS (standing 310, 548 pts). HLTV's Elisa BreakOut Series 2 group draw and schedule put WBT and ROUNDS in exactly the slots HotSpawn fills with WROTBERRY and RoundsGG. Five of the six rows are therefore resolvable from sources already in the repo.

Sources: https://github.com/ValveSoftware/counter-strike_regional_standings/blob/main/live/2026/standings_global_2026_10_05.md · https://www.hltv.org/events/9332/elisa-breakout-series-2 · https://www.hltv.org/events/9332/matches

R-C0-2 — Third-party sites list a different roster for 'WROTBERRY' than Valve and HLTV do.

bo3.gg, egamersworld and strafe.com give WROTBERRY the five fl1peR / svemyy / aRTYSAN / tired73 / lyoli. That is Valve's WBT Academy row (standing 130, 911 pts), not the WBT row that HotSpawn's schedule matches. HotSpawn's fixtures follow WBT, so WBT is used and the conflict is published rather than resolved by guess.

Sources: https://bo3.gg/teams/wrotberry · https://egamersworld.com/counterstrike/team/wrotberry-0I2cpR8LZA · https://www.strafe.com/team/wrotberry-cs-go-b4088f/ · https://github.com/ValveSoftware/counter-strike_regional_standings/blob/main/live/2026/standings_global_2026_10_05.md

R-C0-3 — HLTV contradicts itself about LFO 10's ranking.

On the match analytics page HLTV writes “LFO 10 is worse ranked (Unranked)”; on the event overview for the same tournament the seed column shows #170 LFO 10. No rating is taken from either, and the row stays blank.

Sources: https://www.hltv.org/betting/analytics/2399301/forze-reload-vs-lfo-10-cct-2026-europe-series-11 · https://www.hltv.org/events/9442/cct-2026-europe-series-11

R-C0-4 — The committed Valve snapshot is nine days older than the ranking HLTV displays.

The repo holds standings_global_2026_10_05.md. Listing the repository's live/2026 directory during this session shows 2026_10_05 is the newest file Valve has published there, yet HLTV's team page displays a Valve rank of #64 for WBT against #60 in the file, and #113 for ENCE against #105. Either Valve publishes an update somewhere other than that directory or HLTV re-derives the ordering. The difference is flagged; the repo's official file is what the model uses.

Sources: https://github.com/ValveSoftware/counter-strike_regional_standings/blob/main/live/2026/standings_global_2026_10_05.md · https://github.com/ValveSoftware/counter-strike_regional_standings/tree/main/live/2026 · https://www.hltv.org/events/9332/elisa-breakout-series-2

R-C0-5 — The HotSpawn lobby's own counter still does not match its fixture list.

The lobby header read 68 matches this week while its own tier filter read All tiers (89), B (25), C (60), S (4) and the rendered card list was shorter again. Inherited sessions already published this as unexplained; it is reproduced here for continuity and left unexplained rather than guessed.

Sources: https://play.hotspawn.com/lobby

R-C0-6 — The lobby's displayed kickoff times are not UTC.

HotSpawn's cards are labelled with local times; the embedded fixture payload carries UTC epochs. HLTV renders the same matches four hours behind the UTC values the board stores, which is a display-timezone difference, not a scheduling conflict. Only the UTC values are used.

Sources: https://play.hotspawn.com/lobby · https://www.hltv.org/events/9332/elisa-breakout-series-2
