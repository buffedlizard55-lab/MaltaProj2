Method & sources

1. Fixture discovery (reverse-engineered HotSpawn lobby)

Read the Angular script#ng-state fixtures embedded in the public HotSpawn lobby (the /api/v1/fixtures response the lobby itself renders). Only the lobby_page + api seen_in rows are the current pickable inventory; an api-only row is not same-capture evidence. The response includes epoch ms scheduled_start_time and lock_time (lock = start − 6 min, verified lock_offset_sec: 360) and the published permalink map — we use only the permalink HotSpawn itself published for that fixture id, otherwise the lobby URL and the row is flagged. HotSpawn never supplies a probability.

2. Market first (no-vig, source-linked)

Try public Pinnacle (sport 12, series-winner), Bovada (coupon JSON, match moneyline), Melbet (LineFeed Get1x2, sport 40) and the Kalshi exchange (series KXCS2GAME, explicit full-match rules + two-sided books). Join both participants and source kickoff (max 5-min discrepancy); reject live markets, props, unknown times and stale quotes (quote age & cache-adjusted fixture age ≤4h). For decimal odds dA,dB: pA = (1/dA)/((1/dA)+(1/dB)), pB = 1−pA. Combine accepted sources with declared weight 2 for Pinnacle and 1 for others — a modelling choice, not an official win probability. Market picks are never blended with rating estimates.

3. Fallback research only for market gaps (HLTV → esportsbooks → originated line)

Where no two-sided market price is joined, read HLTV betting analytics first (ranking, form, H2H, roster/stand-in notes), then egamersworld odds widgets / Polymarket listings / bo3.gg coefficients. A Kalshi full-match fallback requires two active binary contracts, matching teams, consistent explicit originally-scheduled CS2 match rules, verified EDT/EST/UTC timezone and two usable bid/ask books (spread ≤10c). Retained official JSON must reproduce both rules and prices offline. These normalized yes midpoints are estimates, not executable odds; volume can be 0. This fallback is used only for market gaps and never changes an accepted bookmaker estimate. For the 7 former gaps in this audit we provide a research-resolved pick (e.g. BET-M 66%, Nemesis 64%, Enjoy 55% …) — each is an estimate from cited HLTV/EGW facts, not a bookmaker price, with the limitation published per row.

Use two uniquely identified teams in Valve’s official VRS standings (snapshot 2026_10_05; refuse duplicate roster names and unproven aliases). Standings older than 14 days are ineligible. Where a research pick still needs a numeric estimate and both teams have a unique VRS row, apply a logistic rating-difference model using Valve’s Glicko code with fitted slope k=0.25 (calibrated on the market board’s 5 eligible pairs): pA = sigmoid(k·G·ln(10)/400·(ptsA−ptsB)), RD=75, Q=ln10/400, G=1/√(1+3Q²RD²/π²). Fitted k=0.25, pairs_used=5, fitted=False. A model-only estimate is not a bookmaker line and has no claimed out-of-sample accuracy. No sibling/floor ratings, ambiguous-slot joins or default 50/50s. Missing inputs stay flagged.

4. Expire, flag, retry (4–8h)

Quotes and cache-adjusted fixture observations must be ≤4h old. Preserve last-known inventory on fetch failure but never reset its evidence age. A backup timestamp cannot replace missing/failed/invalid/future retained HTTP metadata. When both HTTP and backup clocks exist, the earlier one and unchanged cache Age bound eligibility. Recheck all sources every four hours with GitHub Actions (every-match-c64a5e19.yml at 12 */4) and publish only after tests and source replay succeed. Schedule delays, caches and provider blocks are reported, not hidden. This audit rebuilds from the same snapshot — a page rebuild is not a new source observation. HLTV reads are manual (403 in automated capture) with URL and UTC read time cited per fact.

5. Contrarian-but-not-stupid ladder

Safe pick is always the highest fair probability. An optional climb pick is declared: underdog fair probability ≥30% floor, HotSpawn ownership on that side ≤20%, leverage ≥2.0×, and at least 2 verified context flags (H2H, form, roster, VRS gap, streak). Max 3 climbs, cheapest expected-points sacrifice first (cost = points·(fav−underdog)). Crowd never enters the probability — only the climb comparison. For TWC semis not on HotSpawn there is no ownership, so only the floor + flags apply (published as watchlist).
