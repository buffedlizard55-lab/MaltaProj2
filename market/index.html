What this board is

Every match the HotSpawn Pick'ems lobby lists, with an external betting line per match (never HotSpawn) and the no-vig win probability derived from those prices. Each row links the exact source it was read from and the time it was read. Where no external price exists, the row is left blank and flagged — the board never invents a number.

HotSpawn's crowd "picked %" is shown as reference only. It is never an input to any probability on this site.

How to read a row

  • External line(s) — the quoted decimal prices for both teams, the implied no-vig probability per source, the bookmaker overround, the source link and retrieval time.
  • Derived probability — the mean across the sources that quote the match (p = (1/d) / Σ(1/d) per source, then averaged).
  • Pick — the higher-probability side of that consensus. This is what the market says, not a prediction by this site.
  • Originated estimate (model) — a clearly-labelled model value for CS2 fixtures that no reachable book prices, computed from Valve's official regional standings (p = 1/(1+10^(-(Ra-Rb)/400)) on VRS points). It is never mixed into the market consensus and is never shown as a market line. Everyone else stays blank.
  • Verification — "verified from external line" only when a source quote was joined to the fixture; otherwise the flag explains what is missing.

Two different things are on this page on purpose: market numbers (quoted prices from bookmakers/prediction markets, each with its source link) and model numbers (our own originated estimate, labelled, only where no market price exists). They are never blended.
