How a probability is produced

  1. A source price is read for both outcomes of the match moneyline (never map handicaps, never outrights).
  2. Each price is converted to an implied share q = 1 / decimal_odds.
  3. The shares are normalised to remove the bookmaker margin: p = q / (qa + qb) (proportional no-vig).
  4. If several sources quote the same match, the board shows the arithmetic mean and the spread.

Joining a price to a fixture

A price is only used when both participants match the fixture by normalised name (with a small, reviewable alias table) and either the source's start time is within 90 minutes of the fixture start, or — when the source publishes no start time — the competition names agree. When a source lists the teams in the other order, prices are swapped and the row says so. Rejected quotes are kept in data/expanded/quotes.json and counted in the summary as "unused".

Raw evidence committed with this site

  • data/lines.json — fixtures, quotes, joins, probabilities, flags
  • data/quotes.json — every raw quote with source URL, market id and time
  • data/collection_log.json — per-source status incl. failures
  • data/fixtures.json — the lobby fixture snapshot used for this run

Method limits — read this before trusting a number

  • Prices move continuously; the timestamp on each row is the only guarantee of when a price was true.
  • A "pick" here is the market's favourite, not a prediction. Favourites lose.
  • Coverage is uneven by design: large tournaments are quoted by several books, small tier-C tournaments by few or none. Unquoted matches stay blank.
  • No HotSpawn number is used anywhere in the arithmetic.
