Method

  1. Inventory. All fixtures come from the official Hotspawn fixtures API (phpstack-1372681-6459848.cloudwaysapps.com/api/v1/fixtures, reverse-engineered from the play.hotspawn.com lobby by earlier sessions; refreshed upstream ~hourly). Nothing hand-entered.
  2. External lines. Prices captured from Bovada's CS2 coupon, Pinnacle's Arcadia guest API (primary series moneyline s;0;m), and Kalshi's KXCS2GAME binary series (yes bid/ask midpoints). Raw captures with retrieval timestamps: data/dd2b7fee/lines_snapshot.json.
  3. No-vig. Book prices divided by their implied sum (overround removed). Kalshi is an exchange: midpoint used directly; thin/wide/seed books flagged — exchange seed books (6¢/94¢ both sides, zero volume) are treated as NO line.
  4. Consensus. Published P(pick) = mean of source estimates for the picked side; [low–high] shows the spread. Single-source rows are labelled. HLTV is a qualitative cross-check only.
  5. Never crowd-derived. Hotspawn pick-percent fields exist in the feed but are never read here.
  6. Honesty. No line → blank + flagged. Schedule disagreements (e.g. MIBR–BC.Game and Heroic–Envy at Oct 15 10:00Z per Hotspawn+Kalshi but Oct 14 16:30–22:30Z per Bovada/Pinnacle) are published. Unconfirmed aliases are listed, not silently merged.
  7. EV. points × P(pick). Pick'em points (2–7 per fixture) come from the fixtures API offered_points field.

Sources

  • Hotspawn CS2 pick'em lobby · fixtures API (inventory + points + locks only)
  • Bovada — Counter-Strike 2 (9 lobby matches priced)
  • Pinnacle — CS2 hub (verbatim per-matchup API rows linked on the board)
  • Kalshi — KXCS2GAME (21 events; per-event API rows linked)
  • HLTV betting analytics (cross-check only)
  • Polymarket (checked — no match markets; see Flagged)

Refresh loop

The repo's upstream pipeline refreshes the inventory about hourly; .github/workflows/fresh-dd2b7fee.yml re-runs this builder plus tests on that cadence. Line captures are in-session snapshots — each source's retrieval timestamp is shown on the landing page (2026-10-13 22:31 - 23:20 UTC).
