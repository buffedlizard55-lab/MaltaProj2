Everything that could not be confirmed cleanly, with the source that shows it. None of these items changes a pick silently: each is either excluded from the numbers or stated on the row it affects.

F1 · Polymarket lists a different opponent for the same 22:00 UTC Los Niños fixture

Polymarket's cs2-ale1-ln-2026-10-21 describes 'Alianza Lima Esports vs Los Niños', 21 Oct 22:00 UTC, CCT South America Series 7 Round 5. HLTV's match 2399865 lists 'Zetta vs LOS NINOS' at the same time and event. Both cannot be right; HotSpawn follows HLTV. The Polymarket market is quoted 0.50/0.50 with a 0.05 bid / 0.95 ask and $5 volume, so no price was taken from it.

F2 · Valve publishes two CYBERSHOKE rows with different rosters

2026-10-05 global standings: #61 CYBERSHOKE 1201 pts (Alkaren, alpha, Mokuj1n, nota, yiksrezo) and #171 CYBERSHOKE 786 pts (alpha, bl1x1, fluffy, glowiing, Mokuj1n). HotSpawn's 'ex-CYBERSHOKE' cannot be joined unambiguously, so the rating is only a sanity check for that fixture; the pick uses the bookmaker price.

F3 · Aggregated odds page mixes two bookmakers in one two-way line

kushvsporte.ru shows П1 1.12 labelled PARI and П2 5.59 labelled WinLine. Best-price aggregation understates the true overround; the no-vig split (83.31% / 16.69%) is therefore an estimate of the market. The raw decimal odds are published so the arithmetic can be re-done.

F4 · Placeholder 1.8/1.8 quotes rejected

egamersworld publishes 1.80 / 1.80 with 0% / 0% for both fixtures researched here (CYBERSHOKE–BlinkDagger, Zetta–LOS NINOS). Symmetric 1.80/1.80 with zero volume is the site's unfilled default, not a line; it is excluded.

F5 · Upstream board's track-record block is not reproducible

The source board's track_record.by_basis reports 90.6% (market) and 69.2% (model) hit rates over 6,908 settled rows. Prior verification sessions found the settled rows re-derive the pick from the result, so the figure cannot be quoted as an out-of-sample record. It is deliberately not shown anywhere in this section.

F6 · Valve standings snapshot is 16 days old

The newest published file is standings_global_2026_10_05.md (checked via api.github.com, 388 rows). Valve publishes roughly monthly, so the model rows can lag roster changes. Affects every VRS-model and originated row.

F7 · One open fixture is not on the lobby page

The capture carries 'Wildcard v DENDELE' (12 Nov) from HotSpawn's public fixtures API but the lobby page's weekly view does not show it. It is kept on the picks list (it is a real HotSpawn fixture) and marked in its row.

F8 · HLTV publishes no odds; HLTV ranks and VRS ranks disagree

HLTV's match pages for these fixtures carry a betting panel with no numbers, so HLTV is used for identity, rosters and form only — never as a probability. HLTV's VRS widget shows Zetta at #366 while Valve's 2026-10-05 file lists #357; the official Valve file is used.
