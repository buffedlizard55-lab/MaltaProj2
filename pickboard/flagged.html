Irregularities

F1Two boards in this repository used Valve's un-fitted slope (k=1) and produced probabilities up to 23 points away from the calibrated board for the same official rating pair

data/fe803b80/board.json carries calibration n_pairs=5, fitted=false, k=1.0 (below that session's own minimum of 6 pairs) yet still publishes VRS-model probabilities. data/51197e5b/board.json and data/36495748/board.json use k=0.430779 fitted on 60 market pairs. Same ratings, different answers: HOTU vs The Huns 98.4% vs 76.7%; FlyQuest vs Staqued 99.2% vs 84.8%. This session publishes one calibration, fitted on the 60 pairs, and refuses to publish a model number it could not fit.

Files: data/fe803b80/board.json, data/51197e5b/board.json, data/36495748/board.json, data/f7279a54/calibration_pairs.json · verdict: irregular

F2Dormant duplicate rosters were used by an earlier board, changing a pick by up to 26 points

Valve publishes one row per roster, so three open fixtures have two rows under the same name. data/fe803b80/board.json priced them with the dormant roster in every case: benched gods #329 (516 pts, last counted match 2026-05-08) instead of #157 (811 pts, 2026-10-02); The Huns #213 (701, 2026-05-12) instead of #122 (944, 2026-10-04); Banda Chuya #373 (402, a two-player roster) instead of #165 (801, 2026-10-04). This session selects the five-player, most recently active roster and publishes the rejected candidate and the probability it would have produced.

Files: data/fe803b80/board.json, data/86f3af65/valve/standings_global_2026_10_05.md, data/86f3af65/valve/details/ · verdict: needs review

F3A usable Melbet price for UNiTY vs Apogee was never joined because of a sponsor-name variant, leaving the row blank on one board and model-only on another

Melbet lists 'UNiTY vs Apogee Esports' at 2.355 / 1.54 for 2026-10-22 14:00Z in 'CS 2. Stake Ranked Closed Qualifier'; HotSpawn lists 'UNiTY vs Apogee Betclic' at the same minute in 'Stake Ranked Episode 6: Closed Qualifier'. This session applies the alias, prices it from Melbet (Apogee 60.4%) and flags the 47-point disagreement with the rating model as contested.

F4The canonical collector can never join a Kalshi quote (start time hard-wired to None)

scripts/f7279a54/collect.py::kalshi_start() returns None for every event, and core.match_quote() rejects a quote without a verifiable kickoff. The exchange therefore cannot enter any pick on that board by construction, even when both names and the ticker time agree. This session keeps the same rule (no guessed timezone -> no join) but publishes every such quote as an observation on the Flagged page instead of dropping it silently.

Files: scripts/f7279a54/collect.py, scripts/f7279a54/core.py · verdict: irregular

Kalshi lists 'Los Ninos vs Alianza Lima Esports' at 22:00Z, the same minute as HotSpawn's 'Zetta vs LOS NINOS'. They share one team. Any matcher that accepts a single-name join would silently import the wrong price; this session requires both names plus an agreeing kickoff.

F8The fixture feed carries 78 'scheduled' CS2 rows of which only 13 are still pickable

Many rows keep status 'scheduled' long after their lock time has passed (61 such rows in the canonical capture). A consumer that treats 'scheduled' as 'open' will publish picks for matches that cannot be entered. This session opens a fixture only when status is scheduled AND its lock time is in the future.
