Probability rules

  • Market: per-book no-vig p = (1/da) / (1/da + 1/db), arithmetic mean across accepted books (Pinnacle, Bovada, Melbet; Kalshi exchange midpoints only as flagged fallback). A quote joins a fixture only on agreeing teams (canonical names) + kickoff; alias joins additionally require published roster/slot proof.
  • Model (originated): Valve's own Glicko expected-win curve on official VRS points, p = sigmoid(k·C·Δ) with RD=75; k=0.4213 market-calibrated (session 7177d07f fit, retained in-repo), k=1.0 shown as sensitivity. Source: Valve standings 2026-10-05.
  • Bound: exactly one side rated → opponent priced at the list floor (381 pts); published as ≥, using the weaker duplicate row where a name is duplicated.
  • Blank: no price + no rating pair → no number, no pick, listed on Unresolved with the attempt ledger.
  • Safe pick = argmax probability. Climb switch requires dog ≥35%, leverage (prob − crowd) ≥15pp, ≥2 verified context flags; max 3/day. Context never moves the % — it only gates the switch.
