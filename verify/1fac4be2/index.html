5 · Method and limitations

  • Nothing is inferred. A value with no retained source stays blank and is flagged.
  • HotSpawn is never a probability input. every published probability is re-derived from a retained quote or Valve VRS points; HotSpawn ownership is stored but never an input
  • Ownership is context. 83 published probabilities were re-derived without reference to a crowd share.
  • Capture, not streaming. Quotes and fixtures are snapshots; each row carries its read time and a four-hour eligibility bound.
  • This verifier is offline and deterministic. It re-uses the same retained evidence the site publishes: This verifying session runs with an allow-listed egress (GitHub only), so it cannot re-fetch HLTV, HotSpawn or a bookmaker page itself. Every external fact below is therefore checked against *retained* captures already committed by sessions that did have live access, and against the scheduled workflows' live run status from the GitHub API. Live re-fetching happens in GitHub Actions, not in this sandbox — that is a documented limitation of this verification, not a claim that the sources were unread.
