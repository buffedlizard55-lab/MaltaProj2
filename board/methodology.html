Methodology

HotSpawn pick'em fixtures priced from outside sources
BoardMethodologySources & auditFlagged for review
Every number on this site is produced by pipeline code in this repository from a named public source. Nothing is typed in by hand, and HotSpawn is never used as a probability input — only as the list of fixtures to price.

1. Fixtures

Fixtures come from the pick'em lobby's own public JSON API, discovered in the lobby page's server-rendered payload: https://phpstack-1372681-6459848.cloudwaysapps.com/api/v1/fixtures (page: lobby). Snapshot 2026-10-13T21:34:36Z: 406 fixtures in the pick'em window (92 CS2, 314 LoL) out of 11570 rows the endpoint has ever returned. A fixture is dropped only when the API reports it as ended or its start is more than 24 h in the past. The lobby's own "picked %" is a crowd number; it is displayed for reference and never enters any calculation.

2. External prices

For every fixture the pipeline looks up real moneyline prices at outside sources — never at HotSpawn:

3. Matching rules

  1. Both participants must be equal after normalisation (case, accents, punctuation and documented club suffixes removed), in either order; a reversed source listing has its prices reversed.
  2. If the source publishes a start time it must agree with the fixture within 90 min of the fixture start.
  3. Kalshi's two outcome markets are paired per event; its settlement rule supplies the tournament and the match's original schedule (the exchange's own occurrence_datetime is padded with the settlement window and is deliberately not used as a kickoff).
  4. One quote is assigned to at most one fixture. Ambiguous candidates are rejected and logged — 37 accepted vs 1035 rejected candidate decisions in this snapshot; the rejects are almost entirely markets for matches that are not in the pick'em list at all.

4. Probability maths

Bookmaker decimal odds: q_i = 1 / odds_i, then p_i = q_i / (q_a + q_b) (proportional no-vig; the book's margin is reported per row as q_a + q_b − 1). Kalshi: p_i = mid_i / (mid_a + mid_b) with mid_i = (yes_bid + yes_ask) / 2. When several sources quote the same fixture the row shows their arithmetic mean, plus the min–max range in the data file. These are derived quantities, not forecasts and not source quotes.

5. Originated lines (matches no book prices)

For a fixture with no external quote the pipeline tries to originate its own line from the same external markets: every collected quote — including matches that are not in the pick'em — is one observation logit(p) = strength_A − strength_B; a Bradley-Terry model is fitted by maximum likelihood over that graph, and the fitted strengths give a probability for any pair of teams the market does price. Teams the market never prices stay unverified instead of receiving a made-up number.

6. Limits, stated plainly

  • HotSpawn's lobby lists many fixtures whose kickoff is long past; no live market exists for those and none is published. Currently 61 of 92 rows.
  • Kalshi books for these low-tier matches are thin: wide spreads and little traded volume are shown per row.
  • Pinnacle prices only some of these tournaments; tier-C events (Elisa BreakOut, Urban Riga, Svenska CS-Ligan, DraculaN) are largely unpriced by the sources reachable from this environment.
  • Nothing is extrapolated from HotSpawn's crowd pick percentages, and no value is ever filled in by hand.
