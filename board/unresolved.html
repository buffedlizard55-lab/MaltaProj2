D · What each method can and cannot do

MethodUsesLimitation
External prices (Pinnacle, Bovada, the 1xBet platform LineFeed, Kalshi, Polymarket, Thunderpick via bo3.gg) The books' own two-way prices, margin removed with the proportional no-vig method. Only fixtures a book lists are covered. Tier-C qualifiers and regional cups are often unlisted, and a thin exchange book is refused rather than used.
Official Valve VRS Valve's published regional standings (snapshot 2026_10_05), read from the official repository. Published roughly monthly, so it lags the lobby by up to a few weeks, and it lists rosters, not fixtures. A roster that is absent from the table has no published rating.
One-sided VRS bound One rated roster against an unrated opponent placed on Valve's published 400-point floor. The floor is an assumption about the unrated side; a real unlisted roster can be stronger, so the number is a bound, not a probability.
Alias candidate A HotSpawn listing under a former name matched against Valve's official rows for that name. The identity is a candidate, not a confirmed match: HotSpawn may list a different roster under that name. The weakest official row is used so the estimate stays conservative.
bo3.gg published results / ranking Finished-match results and the published world ranking of each team. Many tier-C teams have no published ranking and few finished results; the Elo over a handful of matches is noisy.
HLTV The public HLTV team ranking, if the page answers an automated read. Answered not attempted in this build in this build — a blocked page is published as blocked and is never treated as "the team has no ranking".
bo3.gg fixture identity The same slot, the same competition and the same opponent on bo3.gg. Only fires when one side's name matches exactly and the slot and competition agree; no substring or fuzzy matching is used.
HotSpawn Fixture discovery and the final score used to settle the track record. The crowd "picked %" is never read, stored or used as a probability.
Every row has a source link. A row without a source link is a bug, not a gap: the board's contract tests fail if any published row loses its link.
