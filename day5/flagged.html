F3 · The bo3.gg 'rating' field is a tournament-level metric and is not used as a win probability
low

Every match of the same bo3.gg tournament carries the same 'rating' value (for example 0.0416 for the whole of tournament 6050), so it cannot be a per-match win probability. Only bo3.gg's bookmaker coefficients inside 'bet_updates' are used, and only when both sides carry one. This is recorded because the field is easy to mistake for a model probability.

F4 · HotSpawn's own crowd percentages are never a probability input
low

HotSpawn's 'picked %' is carried on every row as leaderboard context only, labelled as such, and is excluded from every probability. The published probability comes from external bookmaker prices, or from the official Valve ratings model when no book prices the match.
