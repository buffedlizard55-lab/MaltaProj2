Method & sources

Source capture: 2026-10-30 06:27:43 UTC. Inventory cache observed: 2026-10-30 02:57:55 UTC.

Source hierarchy

  1. Preserve eligible featured Pinnacle, Bovada and Melbet match-winner consensus, or independently timestamped exchange prices. No dependence on Polymarket coverage.
  2. Only for missing featured prices: try HLTV first (never bypass its access controls), then esportsbook/exchange feeds and bo3.gg published coefficients. A secondary publisher is labelled, not claimed as direct bookmaker verification. Official Kalshi rules can verify an explicit full-match kickoff and both yes bid/ask midpoints; both sides need narrow spreads and ≥20 reported contracts. Normalized midpoints are not executable odds; zero-volume 50/50 quotes do not overrule a rating estimate.
  3. If no eligible price exists: originate a separate experimental rating-model estimate only from two unique official Valve ratings, a fresh check of the latest official file (≤8 h), dated standings ≤35 days old, and at least six current matched market/rating calibration pairs. Duplicate-name rosters are refused.
  4. If evidence is still inadequate, retain the row with blank probabilities/pick and the reason. No lowest-ranked proxy, no unsupported aliases or fabricated research.

Calculations, not source facts

For decimal odds a,b: P(A)=(1/a)/((1/a)+(1/b)); P(B)=1−P(A). Consensus uses the existing source weights (Pinnacle 2; others 1) with one vote per source. Featured probabilities are replayed from raw odds and must match the upstream line to 0.0001.

Originated model: P(A)=1/(1+exp(−k·g·ln(10)/400·(ratingA−ratingB))), with g=1/sqrt(1+3·(ln(10)/400)²·75²/π²). k is a bounded through-origin least-squares fit of market logits against rating deltas using only this capture's prices. This is an unvalidated market-calibrated estimate, not a verified outcome probability or a backtested accuracy claim. It does not account for current veto, lineup or format changes.

Current calibration: 7 pairs; k=0.4768; fitted=True. Valve model · Valve fitting code · Official repository and caveats.

Coverage & freshness

The public lobby transfer state defines membership; the fixtures API is also checked, but its thousands of historical rows do not expand lobby membership. Missing page access preserves the last inventory with its original observation time. HTTP cache Age reduces the usable lifetime. Quotes and fixtures expire after four hours or the lock deadline, whichever is sooner. Started/ended/conflicting rows cannot become current picks. A refresh can legitimately find fewer matches; no count is hard-coded.
