Method & sources

Automatic updates, no manual entry

The picks collector checks the public lobby and external sources every four hours using GitHub Actions. New listed matches are included automatically. GitHub scheduling and source availability are best effort; source failures and missing odds are published on Flagged for Review. HotSpawn’s crowd percentages are never used to estimate a winner.
