How picks are generated

  1. Featured bookmaker lines first. Decimal odds from Pinnacle, Bovada and Melbet are collected, margin removed (no-vig normalization), and consensus probability computed.
  2. Exchange prices. Kalshi regulated exchange bid/ask midpoints fill additional fixtures where a two-sided book exists.
  3. Esportsbooks via aggregators. Thunderpick coefficients published on bo3.gg price tier-C matches other books don't list.
  4. HLTV research. HLTV team pages and event pages provide identity/ranking evidence only. HLTV user vote percentages and HotSpawn crowd picks are never used.
  5. Valve VRS model (fallback only). For matches with no eligible price, win probability is estimated from official Valve Regional Standings points using a calibrated Glicko curve. These rows are clearly labelled "model" and carry lower confidence.
  6. Unresolved stays blank. If no defensible evidence exists, the cell stays blank with the limitation documented. We never invent a 50/50 or use sibling/floor ratings.

Automatic updates

The collector checks the public HotSpawn lobby and external bookmaker/exchange feeds every 4–8 hours using GitHub Actions (no manual input needed). New matches appear automatically; expired picks are hidden client-side after their source evidence deadline or pick lock.
