How to use this dashboard

  1. Choose a match: open All CS2 picks, then search a team or tournament.
  2. Read the line: market prices first; a labelled model only where no accepted market exists.
  3. For leaderboard risk: use the TWC decision sheet. A possible upset is not automatically a good pick.

Automatic updates

The canonical collector is scheduled every four hours at 00:12, 04:12, 08:12, 12:12, 16:12 and 20:12 UTC. It rediscovers lobby fixtures and retries external markets without manual input. GitHub scheduling, caches and provider blocks can delay updates; this is not an uptime guarantee. Quotes expire after four hours or at pick lock.
