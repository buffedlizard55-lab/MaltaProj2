6. HotSpawn listing hygiene

  • 61 stale listings: fixtures the lobby and API still report as scheduled although their kickoff has passed by more than two days (June–July 2026 and two mid-October rows). They are excluded from the open board and listed on the source page instead of being priced.
  • API/lobby disagreement: fixtures present in the public API but absent from the lobby page (or the reverse) are kept only when the lobby page lists them, because the pick'em game is the lobby.
  • Kalshi timestamps: the exchange's occurrence_datetime field is four hours later than the kickoff stated in its own rules_primary text on all 33 open events. The board uses the rules text (EDT/EST → UTC) and never the field. This is documented on Method.

7. Repository irregularities found during the line-by-line review

  • The canonical board never joins Kalshi. scripts/f7279a54/collect.py returns a JSON null from kalshi_start(), so every Kalshi quote is marked start_is_approx and rejected by match_quote(). Result: 13 usable exchange quotes are captured and then discarded every run. This board re-derives the kickoff from the exchange's own rules text; the canonical board is unchanged (owned by another session).
  • A real Melbet line is missed on fixture 1082882. Melbet prices “UNiTY vs Apogee Esports” (event 763696446) at the same 2026-10-22T14:00:00Z kickoff as HotSpawn's “UNiTY vs Apogee Betclic”, but the canonical board leaves the match unpriced and the fallback board fullpicks/ publishes a Valve floor estimate of UNiTY 87.0%. The market has UNiTY at 39.5%, so that estimate is 47 points away from the only real price that exists. The alias is published here and the row is flagged for review.
  • Rendered-vs-data lag on the archive boards. Root pages are only regenerated when a session runs scripts/build_site.py, while sub-boards refresh every 4 hours; at the start of this session the root page advertised a fullpicks snapshot of 14:14:56Z while that board's own data was 18:58:41Z. This board avoids the gap by committing the rendered pages in the same job as the data. Separately, fullpicks/index.html still labels its board “All 19 Open CS2 Picks” while its own summary counts 13 open matches — a hard-coded label.
  • Third-party data that cannot be re-verified here. Some parallel boards quote bo3.gg team pages and match histories. bo3.gg is not reachable from this build environment (connection refused), so no bo3.gg number is used as an input on this site; its claims are left to the boards that captured them and are flagged there.
  • Root landing page. The root page stacks more than ten parallel boards with different policies and conflicting counts (12/12, 9/9, 7/7 …). This board is added to the root page as the single primary action, with the parallel boards kept under an archive heading.
  • Valve snapshot age. The official standings file is 2026_10_05, i.e. the newest Valve publishes; any board claiming a fresher official rating on 2026-10-21 should be checked.
