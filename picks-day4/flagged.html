F1 · high HotSpawn's published scoring has no ownership term, so 'points x (probability - crowd ownership)' differentials are not a payout model

The official how-it-works page states only 'Earn points for every correct pick. Higher tier matches reward more points' plus an unquantified consecutive-correct streak bonus, and the fixtures API points model exposes exactly five multipliers (game, tier, series, stage, tournament) with no ownership field. Several boards already published in this repository rank contrarian value by points x (probability - crowd ownership). That formula implies a payout that HotSpawn does not publish. This desk therefore ranks picks by expected points = offered_points x probability, and treats ownership purely as context.

Sources: HotSpawn how it works · HotSpawn fixtures API row 1081888 (points_breakdown fields)
F2 · high The TWC Malta day-4 semi-finals are not pickable on HotSpawn

The HotSpawn fixtures API returns an empty list for competition 35859 with status=scheduled, and its unfiltered competition response contains only the eleven group-stage/decider rows — no semi-final, third-place or grand-final row. The website schedule does carry 17 Oct rows 1080207 (14:00 UTC, FURIA v 'Waiting for information') and 1080208 (17:00 UTC, Falcons v 'Waiting for information'), and 18 Oct rows at 11:30 UTC and 15:00 UTC with both sides 'Waiting for information'. So day 4's leaderboard points come entirely from the 7 non-TWC lobby fixtures (20 points available), not from the semi-finals. The collector re-checks competition 35859 every run and will pick the semi-finals up automatically if HotSpawn lists them.

Sources: HotSpawn fixtures API, competition 35859, status=scheduled (empty) · HotSpawn fixtures API, competition 35859, all statuses (11 rows, none a semi-final) · HotSpawn tournament page (1080207 / 1080208 schedule rows)

F4 · medium offered_points does not equal base_points x the published multipliers

Tier S: base 2 with game 1.25 and tier 3 multipliers gives 7.5, but the API publishes offered_points 7. Tier B: 2 x 1.25 x 1.5 = 3.75 but offered_points is 3. Both are consistent with truncation to an integer, but HotSpawn publishes no rounding rule, so the values are recorded verbatim and the rounding is labelled a hypothesis, never applied to any calculation.

Sources: HotSpawn fixtures API rows 1080176 (tier s) and 1081888 (tier b)

Differences from other boards already published in this repository

  • ../day4/index.html states "verified: the fixtures API has no TWC Malta competition". That is not what the API returns: competition_id=35859 exists and returns eleven settled rows; only the status=scheduled query is empty. Our conclusion (the semifinals are not pickable) is the same, the stated reason is corrected here. HotSpawn API
  • Several published boards rank contrarian value by points × (probability − crowd ownership). HotSpawn publishes no ownership term in its points model, so that formula prices a payout that does not exist. This desk ranks by expected points = offered_points × probability (flag F1).
  • Some boards cite an "HLTV live Valve-VRS forecast" that puts Aurora ahead of FURIA. The official Valve file for 2026_10_05 puts FURIA ahead. We originate from the official file only and say which snapshot we used (flag F5).

What we deliberately did not publish

  • Any alias we could not verify (for example WROTBERRY ↔ WhiteBIT Team, ex-6666 ↔ 6666, antidaun) — those sides stay unresolved instead of guessed.
  • Any probability for a fixture whose teams are still "Waiting for information".
  • Any streak-bonus optimisation: the bonus value is unpublished, so it is a tie-break only.
  • Any use of HotSpawn crowd percentages as a probability input.
